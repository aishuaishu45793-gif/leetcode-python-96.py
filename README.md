## 🚀 How to Run the Code

1. Clone the repository you want to use:

   ```bash
   git clone https://github.com/aishuaishu45793-gif/leetcode-python-100.py.git
   ```

2. Open the downloaded folder in Visual Studio Code.

3. Make sure Python 3 is installed.

4. Open a Python file and run it using the terminal:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual Python filename.

**Note:** LeetCode solutions often use the `class Solution` format. These solutions are designed to run within LeetCode's testing environment and may require a separate driver or test cases to run independently.
